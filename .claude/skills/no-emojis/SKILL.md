# No Emojis Rule

You must strictly avoid using any emojis in all communication.

## Rules
1. Never use emojis, emoticons, or Unicode pictographs (such as checkmarks, rocket ships, robot icons, stars, or alert symbols) in:
   - Chat responses and explanations
   - Headings, lists, or tables
   - Git commit messages (do not use emoji prefixes)
   - Pull request titles, descriptions, and comments
   - Code comments, documentation files, and roadmaps
2. Replace common emoji patterns with plain text equivalents:
   - Replace checkmark emojis with `[Done]`, `[x]`, or `Passed`
   - Replace cross / error emojis with `[Failed]`, `[x]`, or `Error`
   - Replace warning emojis with `[Warning]` or `Note:`
   - Replace rocket / robot / tool emojis with direct words
3. Ensure all output remains clear, concise, professional, and strictly textual.
